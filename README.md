# 세 단어 서재 (가칭)

랜덤으로 보여 주는 단어 10개 가운데 3개를 고르면, 그 세 단어와 맞닿은 책과 책 속 문장을 추천하는 웹앱입니다.

## 상태

**기획 단계**입니다. 아직 앱 코드는 없고, 기획 문서만 있습니다.

- 기획 문서: [docs/PLANNING.md](docs/PLANNING.md)

## 계획한 내용 요약

- 검색이나 베스트셀러 순위가 아니라, 지금의 기분과 관심을 단어로 고르게 하는 우연성 있는 추천을 목표로 합니다.
- 결과에는 책 제목과 함께 선택한 단어와 연결된 책 속 문장(짧은 발췌와 출처)을 보여 줍니다.
- 흐름: 단어 10개 중 3개 고르기(다시 뽑기 가능) → 추천 책 1권과 책 속 문장, 추천 이유 → 다른 후보 넘겨보기, 결과 카드 이미지 저장·공유.
- 서버와 외부 API 없이 직접 정리한 데이터(JSON)로 동작하는 정적 웹앱(React + Vite + TypeScript)으로 만들고, GitHub Pages나 Vercel에 배포할 계획입니다.

서비스 이름, 책 장르 비율, 결과 노출 방식, 초기 데이터 구축 방식은 아직 정하지 않았습니다. 자세한 내용은 기획 문서 8절을 보세요.
